# Interactive Comparison Artifact

This anonymous supplementary artifact contains 11 side-by-side website-generation comparisons. Each case includes the same task rendered under three conditions:

1. **No Skill** — original prompt only
2. **General Skill** — a general UI/UX design skill
3. **Ours** — web-derived visual skills selected for the task

## Open the artifact

**[Launch the interactive comparison gallery](https://web-skill-dag.github.io/Web_SKill_DAG/showcase/)**

Use **Last** and **Next** in the gallery, or the left and right arrow keys. Each preview is interactive and can also be opened in its own tab.

## Artifact contents

- `showcase/` — the paper-style, three-column comparison interface
- `cases/case-01/` through `cases/case-11/` — 33 standalone static results
- `sites/` — legacy paths retained so previously shared artifact links continue to work

Only built browser assets are included. The artifact contains no credentials, analytics, author metadata, development certificates, or source history.
